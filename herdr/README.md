# `herdr`

Configuration for [herdr](https://herdr.dev)

Run `bash init.sh` to install [herdr-lazy](https://github.com/natori-hrj/herdr-lazy) and replay the
tracked plugin lock in `plugins/config/herdr-lazy/plugins.lock`.

- [Documentation](https://herdr.dev/docs/)  
- [Plugins](https://herdr.dev/plugins)
